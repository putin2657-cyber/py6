# ДЕНЬ 1 — КР1. Приближённые вычисления (3.5 ч)

**Открой в методичке:** тема 2 / 2.2 (погрешности, интерполяция).

## Блок 1.1. Погрешности — 40 мин

Запомни 4 вещи, больше не надо.

- Абсолютная погрешность: `Δx ≥ |x − x*|` (x* — приближённое).
- Относительная: `δx = Δx / |x*|` (часто в процентах: `δx · 100%`).
- Верные значащие цифры: цифра верная, если абсолютная ошибка не больше половины единицы этого разряда.
- Правила переноса ошибки:

| Действие | Абсолютная Δ | Относительная δ |
|----------|--------------|-----------------|
| сложение / вычитание | `Δ(u±v) = Δu + Δv` | считать через Δ |
| умножение / деление | считать через δ | `δ(uv) = δu + δv`, `δ(u/v) = δu + δv` |
| степень `u^n` | — | `δ = |n| · δu` |

**Сделай сейчас (15 мин):** возьми из методички 1 задачу на погрешность. Если нет — вот тренировочная:

> `x* = 2.47`, `Δx = 0.005`; `y* = 1.3`, `Δy = 0.05`.  
> Найди `Δ` и `δ` для `x+y`, `x·y`, `x/y`. Округли результат с учётом погрешности.

Контроль: у `x·y` относительная ошибка ≈ `0.005/2.47 + 0.05/1.3 ≈ 0.0405` (около 4%).

## Блок 1.2. Ньютон (конечные разности) — 70 мин

Нужен, когда узлы **равноотстоящие**: `x_{i+1} − x_i = h = const`.

**Шаг A.** Таблица конечных разностей:

```
Δy_i     = y_{i+1} − y_i
Δ²y_i    = Δy_{i+1} − Δy_i
Δ³y_i    = Δ²y_{i+1} − Δ²y_i
...
```

**Первая формула Ньютона (интерполяция вперёд)** — точка `x` ближе к **началу** таблицы:

```
q = (x − x₀) / h

P(x) = y₀
     + q · Δy₀
     + q(q−1)/2!     · Δ²y₀
     + q(q−1)(q−2)/3! · Δ³y₀
     + ...
```

**Вторая формула Ньютона (назад)** — точка ближе к **концу** таблицы:

```
t = (x − xₙ) / h

P(x) = yₙ
     + t · Δy_{n−1}
     + t(t+1)/2!         · Δ²y_{n−2}
     + t(t+1)(t+2)/3!    · Δ³y_{n−3}
     + ...
```

Правило выбора: смотри, к какому концу таблицы ближе `x`. Не угадывай — посчитай расстояния.

**Оценка остатка (часто просят в КР):**

```
R_n(x) ≈ [q(q−1)...(q−n) / (n+1)!] · Δ^{n+1} y₀     (для 1-й формулы)
```

Если дана `f^{(n+1)}(ξ)`, бери классику:

```
R_n(x) = f^{(n+1)}(ξ) / (n+1)! · (x−x₀)(x−x₁)...(x−xₙ)
```

`ξ` неизвестен → берут max `|f^{(n+1)}|` на отрезке и получают **оценку сверху**.

**Сделай сейчас:**

1. Построй таблицу разностей для узлов  
   `x: 1.0, 1.2, 1.4, 1.6`  
   `y: 1.000, 1.221, 1.490, 1.822` (это примерно e^{x−1}, не обязательно знать).
2. Посчитай `P` в точке `x = 1.1` **первой** формулой Ньютона (возьми до Δ² или Δ³ — как в методичке).
3. Посчитай `P` в точке `x = 1.55` **второй** формулой.

Контроль порядка: `P(1.1)` должно быть около `1.105`. Если получилось 2 или 0.3 — ошибка в `q` или в знаке разности.

## Блок 1.3. Лагранж — 60 мин

Узлы **любые** (и равноотстоящие тоже можно, но дольше).

```
L_n(x) = Σ_{i=0..n}  y_i · ℓ_i(x)

ℓ_i(x) = Π_{j≠i} (x − x_j) / (x_i − x_j)
```

Алгоритм на бумаге (не путай индексы):

1. Выписать все узлы.
2. Для каждого `i` отдельно посчитать `ℓ_i(x*)` в нужной точке `x*`.
3. Сложить `y_i · ℓ_i`.
4. Проверка: если подставить узел `x_k`, должно получиться ровно `y_k`.

**Сделай сейчас:** узлы `(0, 1)`, `(1, 2)`, `(3, 10)`. Найди `L_2(2)`.

Разбор (сверься, когда сам посчитаешь):

```
ℓ₀(2) = (2−1)(2−3) / (0−1)(0−3) = (1)(−1) / (−1)(−3) = −1/3
ℓ₁(2) = (2−0)(2−3) / (1−0)(1−3) = (2)(−1) / (1)(−2) = 1
ℓ₂(2) = (2−0)(2−1) / (3−0)(3−1) = (2)(1) / (3)(2) = 1/3

L = 1·(−1/3) + 2·1 + 10·(1/3) = −1/3 + 2 + 10/3 = 5
```

# ДЕНЬ 2 — КР2. Нелинейные уравнения (3.5 ч)

## Блок 2.1. Отделение корня + график — 40 мин

На отрезке `[a, b]` есть корень, если:

1. `f` непрерывна на `[a, b]`
2. `f(a) · f(b) < 0`  (смена знака)
3. Для единственности: `f'` не меняет знак (функция строго монотонна)

Как делают в КР:

1. Считают таблицу `f(x)` с шагом `h` (часто `h = 0.5` или `1`).
2. Ищут пару соседних узлов со сменой знака — это и есть отрезок отделения.
3. Эскиз графика: оси, 5–8 точек, подпись корня.

**Сделай сейчас:** `f(x) = x³ − x − 1`. Таблица с шагом 0.5 на `[0, 2]`. Найди отрезок.

Контроль: корень на `[1.0, 1.5]`, потому что `f(1) = −1 < 0`, `f(1.5) = 0.875 > 0`.

## Блок 2.2. Касательные (метод Ньютона) — 70 мин

```
x_{k+1} = x_k − f(x_k) / f'(x_k)
```

**Стартовая точка `x₀`:** берут тот конец отрезка, где `f(x₀) · f''(x₀) > 0`.  
Если взять не тот конец — метод может улететь.

Остановка (что напишут в задании, то и используй):

- `|x_{k+1} − x_k| < ε`, или
- `|f(x_{k+1})| < ε`

Оформление таблицы:

| k | x_k | f(x_k) | f'(x_k) | x_{k+1} | |x_{k+1}−x_k| |
|---|-----|--------|---------|---------|----------------|

**Сделай сейчас:** `f(x) = x³ − x − 1`, `ε = 10⁻⁴`.

- `f' = 3x² − 1`, `f'' = 6x`
- на `[1, 1.5]`: `f(1.5) > 0` и `f''(1.5) > 0` → `x₀ = 1.5`

Итерации (сверь 1–2 шага):

```
x₀ = 1.5
x₁ = 1.5 − 0.875 / (3·2.25 − 1) = 1.5 − 0.875 / 5.75 ≈ 1.34783
x₂ ≈ 1.32520
дальше быстро сходится к ≈ 1.32472
```

Если у тебя в методичке ещё **метод хорд**:

```
неподвижный конец — там, где f · f'' > 0
x_{k+1} = a − f(a) · (b−a) / (f(b)−f(a))     (если фиксирован a)
```

Учи хорды только если они есть в бланке КР2.

## Блок 2.3. Схема Горнера — 60 мин

Для полинома `P(x) = aₙ xⁿ + aₙ₋₁ xⁿ⁻¹ + … + a₀`.

Схема:

```
bₙ = aₙ
bₖ = aₖ + bₖ₊₁ · c      (k = n−1 … 0)
P(c) = b₀
```

Те же `bₙ, …, b₁` — коэффициенты `P(x) = (x−c) Q(x) + P(c)`, где `Q` степени `n−1`.  
Чтобы получить `P'(c)`, прогони Горнера **ещё раз** по коэффициентам `Q`.

Зачем в КР: корень полинома уточняют Ньютоном, а `P` и `P'` считают Горнером, без раскрытия степеней.

**Сделай сейчас:** `P(x) = x³ − x − 1` в точке `c = 1.5`.

```
коэфф: 1 | 0 | −1 | −1     (x³ + 0·x² − x − 1)
b:     1 | 1.5 | 1.25 | 0.875     → P(1.5) = 0.875
ещё раз по 1 | 1.5 | 1.25:
       1 | 3.0 | 5.75              → P'(1.5) = 5.75
```

Совпадает с днём 2.2. Если не совпало — схема записана криво.

# ДЕНЬ 3 — КР3. Интегралы + ОДУ (4 ч)

## Блок 3.1. Трапеции — 50 мин

Отрезок `[a, b]`, шаг `h = (b−a)/n`, узлы `x_i = a + i h`, `y_i = f(x_i)`.

```
I ≈ (h/2) · (y₀ + 2y₁ + 2y₂ + … + 2y_{n−1} + yₙ)
```

Погрешность:

```
R = − (b−a) h² / 12 · f''(ξ)
|R| ≤ (b−a) h² / 12 · max|f''|
```

**Сделай сейчас:** `∫₀¹ x² dx`, `n = 4` (`h = 0.25`).

```
y: 0, 0.0625, 0.25, 0.5625, 1
I ≈ 0.125 · (0 + 2·0.0625 + 2·0.25 + 2·0.5625 + 1) = 0.34375
точно 1/3 ≈ 0.333…  — трапеции чуть сверху, так и должно быть (f'' > 0)
```

## Блок 3.2. Симпсон — 50 мин

`n` **обязательно чётное**.

```
I ≈ (h/3) · (y₀ + 4y₁ + 2y₂ + 4y₃ + 2y₄ + … + 4y_{n−1} + yₙ)
```

Памятка коэффициентов: `1, 4, 2, 4, 2, …, 4, 1`.

Погрешность:

```
R = − (b−a) h⁴ / 180 · f⁽⁴⁾(ξ)
```

**Сделай сейчас:** тот же `∫₀¹ x² dx`, `n = 4`. Для параболы Симпсон даёт **точное** `1/3`. Если не вышло — сбились коэффициенты 4 и 2.

## Блок 3.3. Эйлер–Коши — 70 мин

Задача Коши: `y' = f(x, y)`, `y(x₀) = y₀`, шаг `h`.

В русских методичках «Эйлер–Коши» почти всегда такой (улучшенный Эйлер / Хьюн):

**Предиктор (обычный Эйлер):**

```
ỹ_{k+1} = y_k + h · f(x_k, y_k)
```

**Корректор:**

```
y_{k+1} = y_k + (h/2) · [ f(x_k, y_k) + f(x_k + h, ỹ_{k+1}) ]
```

Таблица:

| k | x_k | y_k | f(x_k,y_k) | ỹ_{k+1} | f(x_{k+1}, ỹ) | y_{k+1} |
|---|-----|-----|------------|---------|---------------|---------|

**Сделай сейчас:** `y' = y`, `y(0) = 1`, `h = 0.1`, два шага.

```
k=0: f=1,  ỹ=1.1,  f(0.1,1.1)=1.1
     y₁ = 1 + 0.05·(1+1.1) = 1.105
k=1: f=1.105, ỹ=1.2155, f(0.2,1.2155)=1.2155
     y₂ = 1.105 + 0.05·(1.105+1.2155) = 1.221025
точно e^{0.2} ≈ 1.22140
```

Если в методичке «модифицированный Эйлер» (точка середины) — это другое:

```
y_{k+1} = y_k + h · f( x_k + h/2,  y_k + (h/2) f(x_k,y_k) )
```

Бери **ту** формулу, что в твоём PDF, не обе сразу.

## Блок 3.4. Адамс — 70 мин

Самое длинное задание КР3. Обычно берут **экстраполяционную формулу Адамса 4-го порядка** (Адамс–Башфорт):

```
y_{n+1} = y_n + (h/24) · (55 f_n − 59 f_{n−1} + 37 f_{n−2} − 9 f_{n−3})
```

Чтобы её запустить, нужны **4 стартовых значения** `y₀, y₁, y₂, y₃`. Их считают Эйлером–Коши или Рунге–Куттой (как скажут в методичке). Потом уже шагают Адамсом.

Если в бланке **интерполяционный Адамс** (неявный, корректор):

```
y_{n+1} = y_n + (h/24) · (9 f_{n+1} + 19 f_n − 5 f_{n−1} + f_{n−2})
```

Там `f_{n+1} = f(x_{n+1}, y_{n+1})` зависит от неизвестного `y_{n+1}` → сначала предиктор (явный Адамс), потом подставить в корректор.

**Сделай сейчас (минимум):**

1. Выпиши формулу из **своей** методички слово в слово. Не смешивай 3-й и 4-й порядок.
2. На том же `y'=y`, `y(0)=1`, `h=0.1` посчитай `y₁,y₂,y₃` Эйлером–Коши (уже есть `y₁,y₂`; сделай ещё `y₃`).
3. Один шаг Адамса до `y₄`. Порядок величины: `y(0.4) ≈ e^{0.4} ≈ 1.492`. Если вышло 1.1 или 3 — коэффициенты 55/−59/37/−9 перепутаны.

# Шпаргалка формул (распечатай / держи на втором экране)

### Погрешности
`Δ(u±v)=Δu+Δv`  `δ(uv)=δ(u/v)=δu+δv`  `δ(uⁿ)=|n|δu`

### Ньютон, узлы с шагом h
`q=(x−x₀)/h`  
`P=y₀ + q Δy₀ + q(q−1)/2! Δ²y₀ + q(q−1)(q−2)/3! Δ³y₀ + …`

`t=(x−xₙ)/h`  
`P=yₙ + t Δy_{n−1} + t(t+1)/2! Δ²y_{n−2} + …`

### Лагранж
`L(x)=Σ yᵢ Π_{j≠i} (x−xⱼ)/(xᵢ−xⱼ)`  
`Rₙ(x)=f^{(n+1)}(ξ)/(n+1)! · Π(x−xᵢ)`

### Ньютон для уравнения
`x_{k+1}=x_k − f(x_k)/f'(x_k)`  
старт: `f(x₀)·f''(x₀)>0`  
стоп: `|Δx|<ε` или `|f|<ε`

### Горнер
`bₙ=aₙ`, `b_k=a_k + c·b_{k+1}`, `P(c)=b₀`  
`P'(c)` — второй прогон по `bₙ … b₁`

### Трапеции
`(h/2)(y₀+2Σ yᵢ+yₙ)`  
`|R|≤(b−a)h²/12 · max|f''|`

### Симпсон (n чётное)
`(h/3)(y₀+4y₁+2y₂+…+4y_{n−1}+yₙ)`  
`|R|≤(b−a)h⁴/180 · max|f^{(4)}|`

### Эйлер–Коши
`ỹ=y + h f(x,y)`  
`y_new=y + (h/2)[f(x,y)+f(x+h,ỹ)]`

### Адамс 4 (явный)
`y_{n+1}=y_n + (h/24)(55f_n − 59f_{n−1} + 37f_{n−2} − 9f_{n−3})`

# Типовые косяки (проверь перед сдачей)

1. **Ньютон интерполяции:** взял 1-ю формулу, хотя `x` у правого края таблицы.  
2. **Знак разности:** `Δy_i = y_{i+1}−y_i`, не наоборот.  
3. **Лагранж:** в знаменателе `x_i − x_j`, в числителе `x − x_j`. Перепутаешь — ответ мусор, проверка на узле сразу покажет.  
4. **Касательные:** стартовал не с того конца (`f f'' < 0`).  
5. **Симпсон:** `n` нечётное.  
6. **Адамс:** забыл, что `f_n = f(x_n, y_n)`, и подставил только `x`.  
7. **ε:** остановился слишком рано / посчитал лишние 10 итераций. В КР достаточно до заданного ε.  
8. **Округление:** в промежуточных держи 5–6 знаков, в ответ — сколько просят.
